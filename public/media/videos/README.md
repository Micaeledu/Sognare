# Vídeos da marca

Coloque aqui vídeos institucionais, de processo ou depoimentos em vídeo.

- Um vídeo cujo nome contenha **"hero"** ou **"loop"** (ex.:
  `hero-loop.mp4`) vira o **fundo em loop do hero** — precisa ser mudo
  (sem fala importante, já que toca automaticamente sem som).
- Qualquer outro vídeo vira um **card clicável** na seção "Sobre o
  ateliê" (e um botão "Assistir vídeo" no hero), tocando com som ao
  clicar — ideal para depoimentos falados ou vídeo institucional.
- Se existir um arquivo `<mesmo-nome>-poster.jpg` ao lado do vídeo
  (ex.: `hero-loop.mp4` + `hero-loop-poster.jpg`), ele é usado como
  capa/poster antes do vídeo carregar.

Formatos aceitos: `.mp4`, `.webm`, `.mov`. Prefira arquivos leves e
comprimidos (H.264, ~2 Mbps para o loop do hero) para não pesar o
carregamento da página.
