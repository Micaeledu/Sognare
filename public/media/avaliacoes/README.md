# Avaliações de clientes

Coloque aqui prints de avaliações reais de clientes (capturas de tela do
Google, WhatsApp, Instagram). O site os exibe automaticamente na seção de
Depoimentos, em grid com lightbox. Nunca inventamos depoimento — se esta
pasta estiver vazia, a seção de Depoimentos inteira fica oculta.

Formatos aceitos: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
