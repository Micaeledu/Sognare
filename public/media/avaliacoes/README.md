# Avaliações de clientes

Coloque aqui prints de avaliações reais de clientes (capturas de tela do
Google, WhatsApp, Instagram) — servem como arquivo de referência para
transcrever o texto real em `content/site.ts` (`textTestimonials`).

Atualmente o site **não exibe os prints diretamente** (ficavam com
aparência de captura de tela ao lado do resto do design, conforme
feedback). A seção de Depoimentos mostra o texto transcrito desses
prints, num carrossel. Nunca inventamos depoimento — todo texto em
`textTestimonials` precisa vir de um comentário/print real guardado
aqui.

Formatos aceitos: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
